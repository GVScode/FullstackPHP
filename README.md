# 🚀 Projeto Full Stack PHP com Laravel

> Um projeto completo de estudos em desenvolvimento web, evoluindo dos fundamentos do PHP até aplicações modernas com Laravel, Docker e Tailwind CSS.

---

## 📖 Sobre o Projeto

Este repositório documenta minha jornada de aprendizado em desenvolvimento web com PHP. Aqui você encontrará exercícios práticos, projetos completos e anotações sobre os principais conceitos do ecossistema PHP moderno.

O objetivo é consolidar conhecimentos desde a sintaxe básica até a construção de aplicações profissionais, passando por conceitos sólidos de Programação Orientada a Objetos e utilizando ferramentas modernas como Docker para garantir um ambiente de desenvolvimento padronizado.

---

## 🛠 Tecnologias Utilizadas

| Tecnologia | Versão | Finalidade                                    |
|------------|--------|-----------------------------------------------|
| PHP        | 8.2+   | Linguagem principal do backend                |
| Laravel    | 10.x   | Framework MVC para aplicações web             |
| Tailwind   | 3.x    | Framework CSS utilitário para interfaces      |
| Docker     | Latest | Containerização e ambiente de desenvolvimento |
| MySQL      | 8.0    | Banco de dados relacional                     |
| Git        | Latest | Controle de versão                            |
| Composer   | Latest | Gerenciador de dependências PHP               |


🎯 Objetivos do Projeto
✅ Consolidar os fundamentos do PHP
✅ Dominar conceitos de Programação Orientada a Objetos
✅ Construir aplicações reais com Laravel
✅ Criar interfaces modernas e responsivas com Tailwind CSS
✅ Containerizar aplicações com Docker
✅ Utilizar Git e GitHub de forma profissional
✅ Criar um portfólio sólido de projetos
